# **App Name**: AI Learning Platform

## Core Features:

- Course Display: Display courses in a grid layout with cover image, title, school/teacher name, and source platform.
- Header Navigation: Implement a header with logo, navigation links ('智慧课堂', '助学提升', '学情监测'), and active state highlighting for the current page.
- Filtering: Create filter sections for course status, hot searches (e.g., '电路设计', '微处理器'), and other searches, with clickable tags.
- Dynamic Data Rendering: Use JavaScript to render course data dynamically from a mock data array. Enable live updates on data modification.
- Hover Animation: Add hover elevation effect to course cards.
- Search Implementation: Filter the display to match search parameters (tags/ keywords)

## Style Guidelines:

- Primary color: Midnight Blue (#192349) for the header background, conveying a sense of expertise.
- Background color: Off-white (#F5F5F5) to ensure the page stays bright and professional, in keeping with modern UI standards. It creates a clean backdrop that complements the courses.
- Accent color: Sky Blue (#7AD7F0) is used to highlight interactive elements. It adds visual interest without diverting the eye.
- Font: 'Inter' sans-serif for a clean, modern look in both headlines and body.
- Responsive grid layout for course display to adapt to different screen sizes.
- Use simple, consistent icons for course categories and filter options.
- Subtle hover animation on course cards for a modern and engaging user experience.
